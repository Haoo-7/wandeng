# 晚灯

给两个人在酒店夜里用的本地小游戏。真心话大冒险、情趣骰子、命运轮盘、飞行棋，清单里还有连招、今晚剧本、二选一、倒计时。不联网、不收费、不上传。

## 今晚怎么玩

1. 用 Safari 打开 `index.html`（iPhone 不要用微信内置浏览器，全屏会更好）。
2. 填你们的称呼，选热度：烛光 / 微醺 / 深夜。
3. 共享到主屏幕，房间里像一个独立 App。
4. 一部手机就够：抽完题，点「换人」，把手机递过去。

首页头牌是真心话大冒险，一排三格是情趣骰子、命运轮盘、飞行棋；下面的清单里是连招、今晚剧本、二选一、倒计时，最末单独一组「散场」进「收灯」；底栏进「设置」（边界清单在设置页里）。

**开玩之前先过一遍「边界清单」**：两个人各自对同一条点 Yes / Maybe / No，顶部会实时汇总「共同 Yes / 有 Maybe / 存在 No」。今晚真正该玩的，只是双方都点了 Yes 的那些。

**飞行棋**：42 格（6×7 蛇形），两人轮流掷骰，落到哪格就做哪格的事（抽题 / 一起 / 代价 / 免过 / 前进后退），先走到最后一格的人赢。右上「玩法」共 8 种：3 种按当前热度抽题，5 种各带一副 36 张的递进牌堆（甜蜜日常 → 灵肉合一）。中途刷新不会丢棋局。「一起」格与追上对方的那一格，会从活动卡库的「房间里」堆里抽一件两个人一起做的事。

**收灯**：今晚的结束仪式，不是玩法。三步依次进行——安抚（喝水、抱一会儿、问一句「现在舒服吗」）→ 复盘（最喜欢的瞬间、有没有没说出口的不舒服、下次想继续的点）→ 收住（亲额头把称呼换回来、把手机扣过去、说晚安）。三步走完只剩一颗「熄灯」，按下后金色离场，只剩一行晚安。飞行棋分出胜负后，终局也会直接把「收灯」递到你手边。

两部手机一起玩时，在电脑上运行：

```bash
./serve.sh
```

把终端里打印的局域网地址发给另一部手机即可。酒店 Wi-Fi 隔离有时会拦，那时就继续传一部手机。

> 注意：局域网那一份走的是 `http://192.168.x.x`，浏览器不把它当作安全上下文，Service Worker 不会注册，所以那份没有离线缓存（当普通网页用没问题）。要离线，就用从 HTTPS 部署出去的那一份加到主屏幕。

## 规则

- 随时可以说安全词。默认是「暂停」。
- 跳过要付代价。安全词面板里还能「太过了，热度调低」。
- 任意游戏屏都能用「轻一点 / 加码」直接升降一档热度，并当场按新档重抽。
- 倒计时结束会轻轻响一声铃。手机静音拨片拨到静音时不响（对房间客气），Android 有震动补位。
- 题库只存在这台设备的浏览器里。

## 数据与备份

设置屏（首页底行「设置」）里可以：

- **横屏模式** — 默认竖屏，手机上「请竖着拿」照样挡着横握。打开后可以横着拿，飞行棋变成棋盘在左、题目在右；主要给平板用，手机横过来棋盘只有一指高。
- **全屏** — 支持网页全屏的设备（iPad、桌面、Android Chrome）会给一颗开关，游戏屏右上角也有一颗图标随时可切。iPhone 的 Safari 不允许普通网页全屏，那一档不放假按钮，只告诉你「分享 → 添加到主屏幕」——那是 iPhone 上真正的全屏。
- **导出备份** — 把称呼、热度、安全词、用过的题、边界清单、自定义题、棋局一起存成一个 JSON 文件。
- **导入备份** — 读回那个文件。格式不对或读不了时不会改动任何现有记录，只在底部提示一行。
- **导入自定义题** — 追加进抽题池，格式如下（字段缺失或类型不符的条目会被跳过，不影响整次导入）：

```json
[
  { "kind": "truth",   "heat": 1, "gender": "both", "payload": "一句真心话" },
  { "kind": "dare",    "heat": 2, "gender": "m",    "payload": "一件要对方做的事" },
  { "kind": "scenes",  "heat": 1, "gender": "both", "title": "标题", "setup": "铺垫", "do": "要做的" },
  { "kind": "choices", "heat": 0, "gender": "both", "q": "问句", "a": "A", "b": "B", "doA": "选A做的事", "doB": "选B做的事" },
  { "kind": "timers",  "heat": 1, "gender": "both", "text": "限时做的事", "sec": 30 },
  { "kind": "combo",   "heat": 1, "gender": "both", "q": "先答的题", "dare": "答完要做的事" },
  { "kind": "aftercare", "heat": 0, "gender": "both", "bucket": "soothe", "text": "一句收尾要做的事" }
]
```

`kind` 还支持 `wheel` 与 `penalties`（两者 payload 都是字符串）；`heat` 是 0/1/2，对应烛光/微醺/深夜；`gender` 是 `both` / `m` / `f`。`payload` 这一层可以省掉，把字段直接平铺在条目上。`aftercare` 的 `bucket` 是 `soothe` / `debrief` / `close`（安抚 / 复盘 / 收住）——收尾不分池，`heat` 与 `gender` 参与校验但不影响抽取。

## 开发与验收

没有构建步骤、没有依赖、没有 `package.json`。改完直接用浏览器打开 `index.html`，或者：

```bash
./serve.sh          # 默认 8765 端口
node --test tests/*.test.js
```

`tests/` 下三套：`logic.test.js` 覆盖纯逻辑层（去重键、容错迁移、走格解算等）、`data.test.js` 校验题库与棋盘的数据不变量、`versions.test.js` 是一道发布门禁——它要求 `index.html`、`app.js` 注册的 SW、`sw.js` 的缓存名与预缓存列表，四处版本号完全一致。改了任何静态资源记得同步升版本号，否则手机会拿到旧缓存。
