# 晚灯

给两个人在酒店夜里用的本地小游戏。真心话大冒险、情趣骰子、命运轮盘。不联网、不收费、不上传。

## 今晚怎么玩

1. 用 Safari 打开 `index.html`（iPhone 不要用微信内置浏览器，全屏会更好）。
2. 填你们的称呼，选热度：烛光 / 微醺 / 深夜。
3. 共享到主屏幕，房间里像一个独立 App。
4. 一部手机就够：抽完题，点「换人」，把手机递过去。

两部手机一起玩时，在电脑上运行：

```bash
./serve.sh
```

把终端里打印的局域网地址发给另一部手机即可。酒店 Wi-Fi 隔离有时会拦，那时就继续传一部手机。

## 规则

- 随时可以说安全词。默认是「暂停」。
- 跳过要付代价。
- 热度随时能在暂停面板里调低一档。
- 题库只存在这台设备的浏览器里。
