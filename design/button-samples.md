# 互动按钮样本

范围：游戏进行中的操作区（真心话 / 大冒险 / 过 / 换人），以及同一套规则可延伸到掷一次、抽一题、二选一。先出样本，不改代码。

现有问题：主按钮、次按钮、过题都是 56px 全宽胶囊，圆角 999。层级只靠颜色，手感像表单提交，不像房里的选择。

三种方向都保留：酒黑底 #14090D、灯金 #E8C9A0、酒红 #C45C6A、宋体标题、大触控区。

- A 客房菜单：12–16px 圆角方板，细金边。真心话空心，大冒险酒红实心，换人铜板，过是字不是按钮。
- B 一扇门：真心话和大冒险收成一根对切条。过缩小，换人变成细长铜条。
- C 房卡：横卡，左上角一点铜片。真心话米卡，大冒险酒卡，换人是刷卡条。
