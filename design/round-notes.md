视觉构思：酒店床头灯。首页上半截是无字房间照片，下半截是带静物图的横卡。

素材：
- `hotel.jpg` 从首页设计稿去字后得到
- `thumb-tod.png` / `thumb-dice.png` 从设计稿卡片照片裁切
- `thumb-wheel.jpg` 新生成的轮盘静物

未采用整图当页面。骰子页保留 CSS 三维骰，因为要显示中文动作／部位。

## v21（2026-10-02）· 同一晚、同一盏灯

四轮评审（design/critique/handoff.md）后的重制：

- 素材整套重拍：`hotel.jpg`（设置屏，床头柜上两杯酒 + 领带）与 `hotel-home.jpg`（首页，床上手机与远处的灯）两张不同场景；四张缩略图 `game-*.jpg` 与 hero 用同一光源方向（左上灯晕）、同一色温、同一颗粒——生成后经 `output/imagegen/grade.py` 统一调色（暗部压向 #14090D、加 35mm 颗粒）。
- 设置屏去流水线：两人称呼并排成一对，今晚热度放大为屏内锚点（选中档改灯金），安全词收成一行小注脚。
- 首页改「今晚的目录页」：头牌（真心话大冒险）整宽 + 三件小静物一排；缩略图去描边；服务单维持裸清单（明文决策不动）。
- 细节：热度选中并入灯金系统（--lamp 调深至 #DFB489）、圆角收两档 16/10、AFTER HOURS 字距 0.26em、字阶拉开（字标 22 / 巨标 34–46）、tab 灯芯 44×3 圆头、静物图与输入框描边各自归位。

三轮独立 critic（只看图、全新上下文）评分：7 → 7.5 → 7.8（设置 8 / 首页 7.5），均 pass，无「渲染事故」级问题。遗留两项已知取舍：首页服务单保持裸清单（§D-2 明文决策）；设置屏中部暗区是房间暗部的延伸，critic 读作有意留白。生成与调色脚本存于 output/imagegen/grade.py，原始生成图不入库。

## v22（2026-10-02）· 称呼去性别化

设置屏「男的叫什么 / 女的叫什么」改为「一位叫什么 / 另一位叫什么」；脚注不再指定男生先手（「谁先开始都行」）；JS 兜底称呼统一为「TA」。题库按 m/f 分池的内容架构未动——那是更大的内容工程，另立任务。

## v23（2026-10-02）· 玩法诚实化

四条用户反馈落地：

- 首页「没有盒子」修正为「盒在图上」：圆角与裁剪收进 .media 图片壳，图注移出裁剪区——「真/掷/转/答」的字脚不再被圆角啃掉；波纹随之注入 .media。
- 骰子去点数化：动作骰与部位骰的六面直接刻上该档的动作/部位（数据每档恰好 6×6），掷出即读面，结果纸只承担那句怎么做。
- 轮盘发牌化：进屏发八句上盘，每扇刻那句话的头几个字（象牙扇墨字、深漆扇奶油字），转角按落点反解——停在哪扇念哪句，转盘从随机动画变成真正的抽签器。
- 飞行棋：掷骰改为 3D 点数骰浮层（reduceMotion 直接走格）；两枚棋子撞进同一格触发「追上」——天意抽一件两个人一起做的事；到终点分出胜负后，判词写明「输家得满足赢家一个条件，现在就提，今晚有效」。
