## v23（2026-10-02）· 玩法诚实化

四条用户反馈落地：

## v25（2026-10-02）· 轮盘可读性重构（couple-stark 结构）

用户指出刻在扇面上的字看不清，要求参考 couple-stark。实拍该站确认其可读性来源：盘面无字、结果区常驻、选项列清单。据此重构轮盘屏：

- 盘面去句子刻字，只刻序号 1–12（与清单一一对应）；序号反向旋转抵消盘角（transition 与 .wheel 同曲线），盘转字不转，任何时刻正立。
- 结果纸常驻：没开转是灰态「还没开转」，落定写明「盘上第 N 支 + 那句话 + 谁来做」。
- 新增「本轮选项」两栏编号清单：盘上十二支的全文名单，刚落过的一行奶油高亮、序号点灯金；表头带签筒余量。
- 动作区（转动/过/换人）提到清单之前，再转不用滚屏。
- 签筒机制不变：整池 30+ 洗成一筒，落一支补一支，筒摇空重摇。
- 行为校验：4 转落点序号 = 结果卡 = 清单高亮行全对，筒计数递减。

## v26（2026-10-02）· 收灯：事后安慰仪式

参考 couple-stark 的「余韵收尾」（抱抱、补水、复盘、夸奖，把今晚舒服地收住），补上晚灯缺失的情绪架构：此前每个玩法都是无限抽卡循环，唯一出口是左上角返回——今晚没有「结束」这个动作。

- **新屏「收灯」**：固定三步仪式，不是第十个玩法。① 安抚 → ② 复盘 → ③ 收住，面板一步步亮起（没走到的步骤不在屏上），每步从自己的桶里抽一句；走完只剩一颗金色「熄灯」，按下后金色离场、房间沉到 `--room-sunk`，居中一行「晚安」+ 两个人的名字（暖金 = 灯还亮着，熄灯后屏上不再有金——token 语义自己完成了叙事）。
- **aftercare 内容池**：soothe / debrief / close 三桶各 6 句，不分热度、不分性别（无她/他），措辞按晚灯声线重写；自定义导入契约新增 `aftercare` kind（`{bucket, text}`，heat/gender 参与校验但不参与抽取）。
- **入口两处**：首页服务单下方单独一组「散场 · 收灯」（不进「也可以玩」——收灯不是玩法，裸清单决策不动）；飞行棋终局把「玩法」切换让位给「收灯」，与「再来一局」并排。
- 决策记录：状态只存内存，不持久化（与界面态不持久化同一条原则）；去重键两段式 `aftercare-<bucket>`（USED_KEY_RE 约束）；文本去重测试含全桶查重与性别代词守卫。

## v28（2026-10-02）· 倒计时的那声铃

用户指出倒计时结束没有提示。真实缺口比听起来的大：iOS Safari 不支持 `navigator.vibrate`，原有一行震动只在 Android 生效——iPhone 上计时结束只有数字变化，零提示。

- **Web Audio 现场合成一声轻钟**：E5 → C5 双击（落下的大三度，叮——咚），基音外加 f×2.4 非谐分音给一点铜味，峰值声压 0.22、指数衰减 1.4s——床头座钟，不是闹钟。不引音频文件，离线与预缓存清单不动。
- **手势内预热**：AudioContext 在「开始」的点击里创建/恢复（iOS 自动播放策略），结束时的钟才有嗓子；`chime()` 在 `state !== "running"` 时静默跳过，声音失败不影响计时。
- iOS 静音拨片会压住 Web Audio——视为对房间的尊重，此时仍有 Android 震动与「时间到」字样兜底。
- 行为校验：playwright 拦截 createOscillator 真跑 20s 倒计时——上下文 running、结束恰好 4 个振荡器（两声 × 基音+分音）、零 pageerror。

## v31（2026-10-06）· 把「房间」补进内页

一轮按项目自己的规范做的界面润色。基线与当前版本的全部取证在本机 `design/oil-ui-2026/`（`base/` 改前、`final2/` 改后、`compare/page.png` 前后对照；与 `design/output/` 同类，不进版本库）。

**核心发现**：首页与设置屏有照片、有灯，一进玩法屏世界就没了——纯黑底 + 一张浮着的象牙纸 + 底部一颗金按钮。`combo / scene / choice` 的未抽态最严重，屏上只有两行字。

- **试过给玩法屏加一层顶光，撤了。** 单光源、偏左上（与整套素材同向）的暖金洒落，实测把 `#14090D` 糊成一片棕雾，「关了大灯的房间」这个身份直接没了；而且违反「每块 `.screen` 就是那间房本身：实底，不叠色罩」。结论写在 `:root` 的注释里：**暗房间里唯一亮的东西就是灯下那张纸，空档由纸的尺寸和位置解决，不由光解决**。
- **试过「晚」字压印牌背，被推翻删掉。** 未抽题时那张纸本来是个只写两行字的空盒，我的解法是在上半张纸放一个 6% 透明度的「晚」字压印。用户验收时指出「图层不对、叠在字上面」——量下来水印与那句说明相距 110px，并没有真的压字，但两条批评都成立：水印上沿越过了「连招」下面那条页眉横线；而那道 `text-shadow` 做不出压印，只做出一个硬边的浅色错位副本，看着像重影。更根本的问题是**它不承担任何信息**——既不说这是什么，也不说现在能做什么，纯粹是为填满那块地方添的装饰，正是文件头「克制是删除无贡献的元素」要删的东西。
- **牌背改用已有的牌堆手法**：卡下三层零模糊实色偏移边（第三层带 3px 横向错位——一叠牌不会码得完全齐，齐了反而像个阴影）。未抽态的纸按内容长（168–202px），抽中后长到题面那一档（242–407px），`min-height` 过渡与翻面同一个 520ms，读作「牌摊开了」。不新增任何图形（三帧与 5.3s 录屏见 `motion2/`）。
- **减法**：连招牌背那句注脚「答完点下面，答案会变成要做的事」与背面注脚重复，且讲的是抽中之后的事——整条删掉（HTML 里那份是死标记，一并删）。
- **200% 阅读尺寸下长题目被裁字**（真 bug，改前就存在）：`≤700` 档那条 `max-height: 58dvh` 把纸硬顶在 245px，而一句长题要 368px，墨字从纸的下沿溢到近黑底上 = 读不到。改成 `flex: 0 0 auto` + `max-height: none`：纸按内容长，装不下让屏滚——和 `.board-slot` 那条 v30 教训同一个道理。195×422 / 320×568 / 375×667 / 390×844 / 430×932 五档实测无裁切、无横向溢出。
- **设置屏的空洞换了一侧**：原来整块表单 `margin-top: auto` 沉到底、副标题下面留一整屏黑（v21 评审记为「房间暗部的延伸」，本次按新问题重判）。现在登记单紧跟副标题，余量让给「表单→主按钮」那一段——主按钮本来就靠下停（拇指够得着），它和表单之间的空档读作停靠，不读作空洞。
- **收灯**：「今晚到这里」与仪式块改成 `margin-top: auto` 一起居中，成为一个整体；不再是一个钉在顶上、一个沉在下面、中间一整屏空。
- **过 / 换人 补上可点的边界**：它们从来就是 `<button>`、有 44px 可点高度，缺的只是视觉入口——`border: 0; background: none`，只剩 `--cream-72` 的字，所以读起来像图注。给 `--line-10` 边 + `--room-raised` 底，仍是 `--cream-72` 字，比 `btn-outline` 再轻一档。（交付说明里我写成「升为次级按钮」，不准确：改的是入口提示，不是功能。）
- **顶栏四级重量归位**：「轮到谁」15/500 → 16/600（顶栏唯一要读的一件事）；返回与全屏图标、热度步进的加减号退到 `--cream-72`。
- **飞行棋补回那盏灯**：这一屏没有照片、42 格全是暗档，北极星在这里是断的。终点格整块 `--die-face`（象牙 = 被照亮的物件，是这盘要走去的那盏灯），当前格加 `--lamp-16` 受光面（暖金 = 灯还亮着 / 棋子所在）。格号 10px/`--cream-55` → 12px/`--cream-72`、角标符号 9px → 11px——原来要猜着读。
- **三档棋盘暗色归进 token**：`#170C11 / #1E1016 / #22131A` 是屏里写死的 hex，违反「全部颜色走 `:root` token」，收为 `--board-flat / --board-mid / --board-warm`。
- **设置屏建立层级**：六张一模一样的卡读起来像后台。加一条「数据与恢复」分组页眉（复用首页服务单那套字），数据类面板去实底只留 `--line-10` 线，让「屏幕」这块活设置和末尾的「边界清单」站出来；面板内按钮 48 → 44。
- **首页末组不再被底栏吃掉**：`scrollHeight 907 > 844`，「散场」标签孤零零挂在折线上、收灯那一行整行藏在 tabbar 后面。首页收一档节奏（照片带 26→23dvh、头牌 17→15.5dvh、小静物 4:3→3:2、行高与组间距收紧）把收灯那一行放回折线以上。**真机带底部安全区时折线落点控制不住**，所以「散场」这一组的页眉**不带**横线——挂线会被折线切成一张断掉的表，不挂线只是下一组的过线。
- **骰点占位是假状态**：飞行棋面板那颗 `⚄` 在首掷之前一直显示，等于谎报「已经掷过 5」。清空，`min-width: 24px` 留着位子避免跳版；同时把它从行中间挪到紧跟标题——孤悬中间的那颗会被读成一个来路不明的图标。

**独立评审**：一个无历史上下文的评审者，只看当前 14 张截图 + 本项目自己的规范（`review/spec.md`）、不看源码，按「给已有界面评审」协议走一轮，不打分。采纳：飞行棋北极星断裂（→ 终点格象牙）、骰点假状态与居中摆法、低于 `--cream-55` 的字档核查（占位与角标实测已在 55/72，未违反）。**不采纳两条并留理由**：① 新增 `--ivory-shade` 给象牙物件加左上→右下压暗——违反「全部颜色实色，没有任何渐变底」，且刚验证过任何叠加都会毁掉房间的身份；② 删掉倒计时页眉的「N 秒」——它在计时开始后是「总时长」，与正在倒数的大号数字不是同一个信息，只在静止的一瞬重复。评审指出的「题面卡偏高、下方空洞」经复核为已居中（上下空档 180 / 205），未改。

**用户验收（第二轮，本地 8765 实机看过）**：两条意见。① 「晚」字压印——为什么用、且图层像叠在字上 → 见上，水印删除，牌背改用牌堆边；这是本轮唯一被推翻的新增图形。② 「过 / 换人 之前不是按钮吗」→ 一直是按钮，措辞纠正见上；重量（边 + 实底）保留。
